# Cricket Performance Dashboard – Power BI

Interactive Power BI dashboard comparing ODI career performance 
of Virat Kohli and Rohit Sharma.

## Features
- Career runs trend, boundary analysis, innings distribution
- Filters: Year, Month, Ground
- Player-wise detailed ODI statistics (Mat, Inns, Avg, SR, 100s, 50s)
- Drill-through pages for opposition-wise stats

## Tools Used
Power BI, DAX, Data Modeling

## Data Source
ESPNCricinfo
